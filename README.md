# Forja

App de treinos para o ginásio de casa: escolhes o tipo de treino, o tempo e o equipamento, e a Forja monta a sessão, regista as séries e acompanha a evolução.

- Abre em https://danielgog7.github.io/forja/ e instala no telemóvel ("Instalar app" no Chrome).
- Os dados ficam no dispositivo de cada pessoa. Sincronização opcional com um repositório GitHub privado de cada um.
- IA opcional (Gemini), com a chave gratuita de cada utilizador, guardada só no dispositivo.
- Exercícios e imagens: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (domínio público). Nomes em PT-PT em `ferramentas/nomes_pt.json`; `ferramentas/construir_exercicios.py` gera `exercicios.json`.
